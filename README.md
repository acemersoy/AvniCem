# avnicem.com

Avni Cem Ersoy'un kişisel portföy web sitesi — Junior Software Developer.

Backend, API tasarımı, temiz mimari, veritabanı sistemleri ve siber güvenlik
odaklı bir geliştiricinin portföyü.

## Özellikler

- "Designed-terminal" estetiği — koyu tema, asit-lime sinyal aksanı
- Açılışta boot sekansı, özel imleç, manyetik butonlar, 3D tilt kartlar
- **Çalışan canlı terminal** — `help`, `whoami`, `skills`, `projects`, `contact` komutları
- Filtrelenebilir yetenek grid'i, scroll ile sayan istatistikler
- Mobil uyumlu, `prefers-reduced-motion` desteği

## Çalıştırma

`portfolio/index.html` dosyasını tarayıcıda açman yeterli — derleme adımı yok.

## Yapı

```
portfolio/
  index.html   # iskelet
  styles.css   # tasarım
  script.js    # tüm etkileşimler
```

## Teknolojiler
